# IGNITE AWOKEN CLUB

A responsive single-page public website for IGNITE AWOKEN CLUB.

## Included
- Club introduction, mission and sponsorship approach
- Team and player showcase placeholders
- News and announcement section
- Team sponsorship and player application form previews
- Responsive dark esports-inspired design

## Preview status
The forms currently run as front-end previews only. They do **not** transmit or save applications. User accounts, secure login, a real admin dashboard, persistent team/player profiles, and a news management system still require a backend (for example Supabase) and must be configured before collecting personal information.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Open **Pages** in the left menu.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then Save.
5. Wait for GitHub Pages to publish the site. The public address will appear in the Pages section.
